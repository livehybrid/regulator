# Browser-engine dependencies, deliberately separate from requirements.txt.
#
# Playwright's browser binaries are a few hundred megabytes, which would
# quadruple the base worker image for a capability most runs do not use. So the
# browser engine ships as its own image (worker/Dockerfile.browser) and the base
# image raises a BrowserUnavailable with instructions rather than an ImportError
# if a scenario asks for it.
#
# Install alongside requirements.txt, then fetch the browser itself:
#   pip install -r worker/requirements.txt -r worker/requirements-browser.txt
#   playwright install chromium

# Pinned to the exact version of the base image in worker/Dockerfile.browser
# (mcr.microsoft.com/playwright/python:v1.55.0-noble). The browsers are baked
# into that image at one revision, and a newer pip package expects a newer
# revision: the image then builds green and every container dies at launch
# with "Executable doesn't exist". Bump both together, never one.
playwright==1.55.0
